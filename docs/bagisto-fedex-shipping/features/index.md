Bagisto FedEx Shipping covers the full shipping lifecycle — quoting, packing, labeling, tracking, and validation — with zero code from you.

## The Feature Set

### [Live Rates](/bagisto-fedex-shipping/features/live-rates)

Real FedEx prices at checkout for every allowed service, with delivery estimates, negotiated account rates, handling fees, and quota-protecting rate caching.

### [Package Packing](/bagisto-fedex-shipping/features/package-packing)

Cart items are intelligently packed into weight-capped packages — with store-unit conversion and dimension pass-through for dimensional-weight pricing.

### [Shipping Labels](/bagisto-fedex-shipping/features/shipping-labels)

Create FedEx labels from the admin order screen. PDFs stored on a private disk, costs captured per shipment, download and void built in.

### [Tracking](/bagisto-fedex-shipping/features/tracking)

Pull the latest status and scan events for any label straight from the FedEx Track API.

### [Address Validation](/bagisto-fedex-shipping/features/address-validation)

Validate any address against the FedEx database — from the command line or programmatically.

### [Admin Shipments Page](/bagisto-fedex-shipping/features/admin-shipments)

A dedicated **Sales → FedEx Shipments** page with every label, its status and cost, and all actions — gated by Bagisto ACL.
